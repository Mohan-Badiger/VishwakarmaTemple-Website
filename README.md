## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/project-name.git
````

Navigate to project folder:

```bash
cd project-name
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

OR (CRA):

```bash
npm start
```
